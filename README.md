# 🧶 Amigurumi — Japão que encanta com suas inovações

Este projeto é um site estático que apresenta a arte japonesa do **Amigurumi**, uma técnica de crochê e tricô usada para criar pequenos bonecos e figuras encantadoras.  
O objetivo é compartilhar curiosidades sobre essa arte, sua origem e sua popularidade pelo mundo.

## 💡 Organização do repositório

O projeto foi desenvolvido para demonstrar boas práticas de organização de arquivos em um site estático.  
- Todos os recursos (imagens e ícones) estão armazenados na pasta `media/`.  
- As páginas secundárias ficam em subpastas (`about/`), e os links usam URLs absolutas para garantir compatibilidade no GitHub Pages.
